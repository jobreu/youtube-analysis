# youtube-analysis

Jupyter Lab [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/jobreu/youtube-analysis/main)

RStudio [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/jobreu/youtube-analysis/main?urlpath=rstudio)

Demo notebook for exemplary analyses of *YouTube* data collected with the `R` package [`vosonSML`](https://vosonlab.github.io/vosonSML/)

Created for the masters-level seminar "Erforschung von politischer Online-Kommunikation mit digitalen Methoden" ("Studying political online communication with digital methods") at the University of Duisburg-Essen (winter term 2025/2026).
